Sweep

Derives this node's seed into both key schemes on-device — the classic 64 keys this node runs on, and the 32 block-as-keyuses keys the same seed produces on a -blockaskeyuses node — proves the classic set byte-exact against this node's own wallet, then sweeps everything to one of the new keys in one action. The seed never leaves this dapp.
